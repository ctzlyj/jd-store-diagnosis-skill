# 广告冷启阶段策略（广告部门实战口径）

适用场景：新店或低访客（全店访客 <300）店铺的广告行动项。在给这类店铺写诊断建议时，按本文件的冷启框架执行，不要套用成熟店铺的加量逻辑。
前提：冷启策略在"投前五项"达标后执行（"前五项"清单本身不在现有资料中，诊断时若涉及需向商家确认其内部口径）。

## 冷启投放优先级

1. **快车-全店（第一优先）**：积累基础访客，目标 300 访客
2. **快车全站智能**：初始 ROI 可低于利润值；访客积累后逐步提 ROI
3. **稳赚计划**：近 30 天 1 单即可申请，应报尽报；平台赔付兜底，降低冷启风险

执行顺序：快车全店优先积累访客，再开全站智能扩量。访客 <300 时靠 CPS / 国补 / 官直 + 快车全店积累数据，不要强行加量。

## 流量 & 商品力补充手段

- **对标热卖榜**：参考榜单头部卖点与促销价格，优化自身竞争力
- **价促皮肤多元**：国补 / 官直优先；关注公益皮肤等其他皮肤资源
- **秒杀频道**：间隔 3-5 天分货盘提报，每天进秒杀积累成交；**数字人直播**每天出单持续积累购买数据（每天出单 = 持续积累成交信号，提升搜索权重）
- **价格星级日常维护**：85 折明券 / 暗券保持到手价稳定性，每天关注星级变动。暗券不改展示价、实质降到手价，价格星级 <3 星或到手价高于竞对时优先使用

## 广告冷启四象限（投后前 3-7 天看 CTR & CVR）

- **高 CTR·高 CVR** → 阶梯加量，进入放量流程
- **低 CTR·高 CVR**（少曝光有意愿）→ 换标题 / 主图提 CTR；对标热卖榜梳理卖点；观察 3 天
- **高 CTR·低 CVR**（点了不买）→ 查差评 / 商详卖点 / 图片；价格力不足就上暗券 / 国补 / 官直；观察 3 天
- **低 CTR·低 CVR** → 暂停加量，回查投前五项；价格星级 <3 星 → 暗券 / 国补 / 官直；5 天无改善 → 移出广告池
