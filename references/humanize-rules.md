# 人工口吻规范（去 AI 痕迹）

这份报告是「运营顾问一对一写给商家老板的汇报」，必须让老板觉得是人认真写的、很重视他。以下规则在 2026-09 实际交付中由商家视角复盘确认。

## 必须做的

1. **开场**：「老板您好」+ 一段话说明「我整体捋了一遍」「两边我都核对过」「您按需看就行」
2. **收尾**：「有任何看不明白或需要我帮忙的，随时找我」
3. **口语连接词**：咱们、这块、这事儿、捋一遍、说白了、先说结论、您按需看
4. **表格前的引导**：先给结论再上表，如「先给结论：……再看这张表」「看完这组数，三个判断」
5. **数字口语化锚点**：如「每卖 100 元，约 27 元花在广告上」「这两个词属于有人搜、没人抢」
6. **对不确定的处理要坦诚**：如「我不拿这一天下结论，建议您也对照下当天订单」「这块暂时看不到，我先用……顶上了」
7. **行动清单放人话**：「这些不用一口气全做完：先把 A 类三件办了，B 类这周跟上，就能看到变化」

## 必须删/改的 AI 痕迹

| AI 腔（禁止） | 人话（替换） |
| --- | --- |
| 值得注意的是 / 需要指出的是 | 说白了 / 这里要注意 |
| 综上所述 | 总之 / 整体看下来 |
| 我们建议您 | 建议您 / 您可以直接 |
| 经分析可知 | 看完这组数 |
| 显著提升 / 明显优化（空泛） | 直接给数字：从 X 到 Y |
| 综上所述，建议采取以下措施 | 把动作写成表格，编号 A1/B2 |
| 本报告 / 本文 | 这次我把 / 这份汇报 |
| 首先…其次…最后（长链条） | 直接列点，每点独立成立 |
| 大数据 / 赋能 / 抓手 / 闭环（黑话） | 能干啥、怎么干 |

## 交付前自查清单

- [ ] 开头是「老板您好」，结尾是「随时找我」
- [ ] 全文搜一遍：「值得注意」「综上」「赋能」「抓手」「闭环」——命中即改
- [ ] 每个结论都有数字依据，每个动作都有编号可引用
- [ ] 异常数据（如单日异常）有坦诚说明，不假装没看见
- [ ] JoySpace 发布后评论数 = 0（AI 摘要评论一出现即失败，插入附件必须 --no-summary）
- [ ] 标题无任何前缀（不要「报告：」「诊断：」开头）

## 分寸

- 语气尊重但不谄媚；数据扎心时给出处（「不是凭空说，是榜单/报表里的」）
 - 不要过度承诺：「预计进一步提升」可以，「保证翻倍」不行
- 篇幅服务于老板耐心：结论和行动清单让他 3 分钟内能消化，明细留给他想细究时翻
