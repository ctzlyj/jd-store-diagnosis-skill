# 诊断报告结构模板（九部分）

设计原则：老板先看结论和动作，想细究再往下翻。**行动清单放在第二部分**（结论后面），不是附录——多数老板没有耐心读完报告，要把「需要他们做什么」放最上面。

## 标题与开场

```
# {店铺名} · {年月}经营诊断报告

老板您好：

{月份}的经营情况我整体捋了一遍，跟您汇报一下。数据取到 {end_date}（跟 {compare} 同期对比），
商智和京准通两边我都核对过，广告账户是「{子账号名}」。先说结论，再说要做的事，
明细都在后面，您按需看就行。
```

## 一、一句话结论（含三条核心结论）

- 一段话框出本月主旋律：增长/下滑 × 效率 × 风险，最后一句加粗给方向
- 三条核心结论，每条 2-3 行，必须：
  - 有数字证据（环比/对比期/同行均值）
  - 归因到自身可优化项 vs 行业因素
  - 括号挂对应行动编号（如「对应 B4、C1」）
- 结尾引导：「怎么改：直接看第二部分《行动清单》」

## 二、行动清单（按优先级，可直接排期）

三档排期，每档一个表格，列为 `| # | 动作 | 具体内容 | 预期/观察 |`：

- **A. 立即做（24 小时内）**：断投风险、零订单计划关停等不用等的
- **B. 本周做**：预算重分配、转化修复、手动计划开起来等
- **C. 本月内做**：商品结构、选品方向、长线动作

要求：

- 动作具体到可执行：给计划编号、给词、给出价、给金额，禁止「建议优化」这类空话
- 每条的数字依据在后面章节都能查到（交叉引用如「见 4.6」「见 5.2」）
- 表格后加一句人话收尾：「这些不用一口气全做完：先把 A 类三件办了……哪条看不明白，随时找我」

## 三、核心经营数据（商智）

一张表 12-15 行：成交金额/件数/单量/客户数/转化率/客单价/件单价/浏览/访客/停留/UV价值/加购。加「同行同级均值」列。

正文写法：好指标一句话总结，再点出下滑项和同行差距；不逐行复述表格。

## 四、广告投放诊断（京准通）

- 4.1 账户总览：月环比表（正文留 8 项核心，全 16 项进 Excel）+ 一句话总结 + 商智口径交叉验证
- 4.2 分日趋势：正文只留 5 个关键日子（月初/成本极值/异常日/投产比高峰/放量最高）+ 一段节奏总结，全表进 Excel
- 4.3 计划明细与处置：每条计划给处置建议（加投/保持/降价/关停），这表是商家会逐行看的，不压缩
- 4.4 账户资金与官方提示：余额、充值建议、官方风险提示逐条解读
- 4.5 今日快照：注明仅参考
- 4.6 投放结构诊断（8 维度核查）：全智能托管黑盒的说明 + 由此推出的行动项

## 五、商品诊断

- 5.1 商品 TOP10（按成交金额）：SPU/名称/金额/环比/件数/访客/浏览/转化率
- 5.2 下滑预警：流量下滑/转化下滑 SPU 清单 + 渠道层变化
- 商品结构：上架数/动销数/动销率，点出「陪跑」商品

## 六、行业大盘对照（商智 + 京准通，双口径）

- 6.1 交易口径（商智）：大盘 vs 本店对照表 + 子类目行情表（给出增长/下滑类目）
- 6.2 广告端口径（京准通行业）：行业广告大盘环比、关键词榜单 TOP10（含参考出价）、捡漏机会（热搜×竞争度）、品牌榜（自己上没上榜）、地域 TOP3
- 必须下判断：我们的差距 vs 行业均值、买量成本 vs 行业参考出价

## 七、流量来源结构与搜索词（商智）

- 7.1 流量来源：正文留核心 8 行（站内合计/搜索/推荐/频道/我的京东/购物车/其他/站外合计），其余进 Excel；「怎么读」三要点
- 7.2 搜索词 TOP10：按曝光排；三个机会——大词没转化、高转化小词放大、零成交高曝光词排查

## 八、风险提示

表格：级别（高/中/低）| 风险 | 说明 | 建议。断投、效率下滑、托管黑盒、数据异常等都给级别和对应行动项。

## 九、数据说明

- 数据来源表：数据 | 平台 | 看的页面 | 时间——这是报告可信度的锚，逐行写清楚
- 口径提醒：商智 vs 京准通差异、快照口径、占比求和等
- **如实写看不到的数据**：单品监控、竞品明细等缺什么说什么、为什么、用什么顶上了

## Excel 数据表（附件）

每张 Sheet 对应正文章节，命名「N-主题」：

| Sheet | 内容 |
| --- | --- |
| 1-核心经营指标 | 第三章全量 |
| 2-广告账户总览 | 4.1 全 16 项 |
| 3-广告分日趋势 | 4.2 全量分日 |
| 4-广告计划明细 | 4.3 全计划 |
| 5-SPU明细 | 5.1 全量 |
| 6-下滑商品与渠道 | 5.2 |
| 7-行业大盘与子类目 | 6.1 |
| 8-流量来源与搜索词 | 7.1/7.2 全量 |
| 9-广告8维度覆盖 | 4.6 |
| 10-行业关键词榜单 | 6.2 词表+推荐词（B8 执行清单） |

## 分层压缩原则

- 正文 = 结论 + 动作 + 判断 + 小表证据；完整明细 = Excel
- 会被商家逐行看的表（计划明细、商品 TOP）不压缩
- 每次把大表挪去 Excel 时，正文必须留一句话摘要 + 指向 Sheet 名
